# Revenue Recovery Agent UI

A dark SaaS fintech frontend for the Revenue Recovery Agent project.

## Stack
- React + Vite
- React Router
- Recharts
- Lucide React
- CSS design system (no component library)

## Run
```bash
npm install
npm run dev
```

## Main routes
- `/dashboard`
- `/transactions`
- `/transactions/3658`
- `/recovery`
- `/customers`
- `/analytics`
- `/agent-activity`
- `/settings`

Mock data is kept under `src/data/`, and backend-ready request helpers are in `src/services/api.js`.
